   - 吟遊詩人**鼻鼻**撫琴吟唱「五聖降臨，銀蛇墜於永夜」，預告全篇核心謎團。

   - 距離遞減（80m → 60m → 30m → 10m），配合「……不要往我這裡走」等幽默內心戲。

   - 「我只是唱歌的耶！」「那你剛才是怎麼把三百年前的密道打開的？！」
9. **秘紋術師解鎖石門互動**：
   - 依序點擊「門」、「記憶」、「守望」三道古代字符，重構古代魔法陣啟動石門。
